# Источники: категории и проверенность

Дата инвентаризации 06.11.2026. Категории взяты из исходного задания и известной документации, а не из проверки аккаунтов этим CLI. Ни один внешний адаптер не реализован; локальный импорт проверен на синтетических fixtures. Локальные Google Drive tools могут присутствовать в родительском чате, но это не подтверждает доступ исполняемого пакета.

| Источник/модуль | Назначение и отдельный dataset | Фактическое состояние в MVP |
|---|---|---|
| Labrika: технические/контентные отчёты | URL, ошибки, рекомендации, контент, schema, индексация в пределах отчёта | Возможен локальный pages import только при наличии обязательных полей; реальная выгрузка и mapping не проверены |
| Labrika: позиции | Query/engine/region/device/date/URL/position; отдельная гранулярность | Dataset и адаптер не реализованы |
| Labrika: семантика | Ключи, частотность, кластеры, посадочные и методика | Не реализовано; неизвестную частотность не подменять |
| Labrika: конкуренты | Выбранное ядро, конкуренты, coverage | Не реализовано; не называть обзором всего рынка |
| Labrika: внутренние/исходящие ссылки | Source/target URL, атрибуты и время | Не реализовано; доноры и исходящие ссылки не являются полной базой входящих ссылок |
| Labrika: AI-видимость | Ответ, prompt, platform, упоминание/цитата/позиция, время и метод | Модуль аккаунта и экспорт не проверены; не смешивать с GEO-рекомендациями |
| Labrika: Diff API | Отдельный мониторинг изменений, события/webhooks | API и лимиты не проверены; нет мониторинга |
| Labrika: API описаний товаров | Подготовка контента с отдельным расходом | Не подключён; генерация и публикация не выполняются |
| Яндекс.Вебмастер | Host, queries, индексация/обход/диагностика | Доступы и API не проверены |
| Метрика | Агрегаты визитов/целей, counter, фильтры и закрытые периоды | Не подключена; источник данных из Labrika сохранять как primary_origin |
| Wordstat | Частотность/спрос с регионом и временем | Не подключён |
| GSC | Property, page/query/country/device/date, clicks/impressions/position | Не подключён; средняя позиция не равна отдельному SERP-наблюдению |
| GA4 | Агрегаты поведения/конверсий при необходимости | Не подключён, необязателен |
| Drive | Версии клиентских файлов, fileId и revision | Не подключён; write/read и restoration не проверены |
| Crawl/search | Дополнительный provider в пределах scope/лимитов | Не реализован; готовый экспорт допускается |

На каждый модуль вести отдельные documented/account_verified/executor_verified/export_verified/api_verified, время проверки, scope и ограничения. Шаблон — templates/source-capability.json. Чтение готового отчёта не даёт разрешения запустить новый платный анализ. Прямой доступ предпочесть ручному импорту, когда он действительно доступен, разрешён и проверен; сейчас такого адаптера нет.

Ссылки для следующей проверки: [AI-видимость](https://labrika.ru/help/ai/vidimost-ai), [GEO](https://labrika.ru/help/ai/vidimost-brendov), [мониторинг изменений](https://labrika.ru/website-change-monitoring). Текущий запуск не перепроверял их содержание и не использует их для заявления о live-интеграциях.
