# Tavily как заменяемый источник исследования

Адаптация upstream tools/tavily-guide.md. Назначение — поиск источников и чтение страниц для исследования; не универсальный измеритель SEO-метрик. Обязательность Tavily для всех keywords/SERP снята.

Входы: исследовательский вопрос, рынок/язык/дата, разрешённые источники/получатели, реальная capability и лимит. Действия: выбрать короткие целевые запросы → получить кандидатов → прочитать первичные страницы → проверить даты события и публикации → сохранить locator и релевантные observations → передать evidence в предметную роль.

Объём запросов, операции и pricing проверять в актуальной документации конкретного tool. Не устанавливать или подключать сервис автоматически ради workflow. Поисковый snippet не заменяет чтение источника.

Выход — source-backed research с областью применимости. General search order не равен точной Google/Яндекс позиции; поисковые результаты не дают подтверждённую frequency/KD/DA/traffic share/backlink count. Не выводить эти числа моделью из выдачи. Противоречия/пустые результаты показывать, не маскировать нулём.

Адаптер CLI отсутствует; использовать доступный разрешённый provider либо существующие данные. Не повторять заблокированный или неопределённый запрос другим аккаунтом. Новых paid calls в этой задаче нет.
