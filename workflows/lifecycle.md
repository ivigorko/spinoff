# Полный цикл и фактическая автоматизация

Исполняемый офлайн-DAG в seo_system/config/workflows.json: preflight → import → normalize → technical_findings → report и priority → roadmap → qa. Узлы выполняются одним процессом; успешный локальный пакет регистрируется в одной SQLite-транзакции. Нет multi-worker, leases, фоновой очереди, автоматических retry или внешних side effects. Ошибка до регистрации не публикует принятый run. Результат partial из-за ограниченного покрытия.

Следующие сценарии — инструкции Codex для будущих поручений, **не команды существующего CLI**:

| Сценарий | Минимальные входы | Результат и gate |
|---|---|---|
| Семантика/контент | Рынок, подтверждённые ключи/кластеры/частотность, URL, региональный SERP при наличии | clusters + mapping + content briefs; неизвестная частотность остаётся неизвестной |
| Ссылки | Проверенные внутренние/исходящие или входящие ссылки с происхождением | Находки строго по охвату; доноры не равны входящей ссылочной базе |
| AI-видимость | Платформа, prompt, рынок, время, raw answer, упоминание/цитата/позиция и метод | Отдельные наблюдения, не обещание видимости; GEO-рекомендации не подменяют измерения |
| Полный анализ | Валидные результаты реально доступных модулей | report → priority → roadmap → coverage → critical QA; отсутствующие ветки явно partial |
| Подготовка изменения | finding/task, свежая страница, keyword mapping при необходимости, revision | diff/текст, acceptance test, риск, rollback; без автоматической публикации |
| Внедрение | Принятый патч, baseline revision, полномочия на конкретную среду | Сначала drift check, затем фактический release ID; при неопределённости сверить состояние до повтора |
| Проверка | Release ID, время, ожидаемые значения, URLs | Новый сбор после релиза, HTTP/HTML/DOM/canonical/robots/счётчики по затронутому объёму; verified либо verification_failed |
| Измерение | Baseline, журнал релизов, сопоставимые закрытые периоды аналитики | measured/inconclusive/awaiting_measurement; сезонность и другие изменения раскрыты |

Полный цикл требует подключения источников и конкретного пилота. Следующий цикл не запускается сам: нужен запрос или действительно настроенное расписание. Не блокировать техническую ветку из-за отсутствия AI-модуля или Wordstat.
