# Навигация полного цикла

Полный актуальный процесс: instructions/flow.md и workflows/agency-cycle.md. Все 11 исходных workflows имеют собственные файлы и canonical DAG в seo_system/config/processes.json. 75 предметных ролей и 12 leaders выполняются Codex; локальный coordinator принимает их work-products и передаёт точные IDs по зависимостям.

Для полного анализа — full-seo-audit; для семантики/контента/конкурентов/ссылок/local/ecommerce/launch/migration/monthly/quarterly — соответствующий workflow. Для узкого действия role:<team.name>, для всей библиотеки направления team:<name>. Не выполнять все команды только потому, что они доступны.

Режимы разделены: инструкция готова → Codex выполнил анализ → продукт проверен и зарегистрирован → разрешённое внешнее применение действительно выполнено → новая техническая проверка → сопоставимое измерение → отчёт → стратегия обновлена. Ни один флаг JSON не заменяет фактического действия или разрешения.

Legacy технический DAG workflows.json остаётся отдельным автоматическим pages import с тремя правилами и всегда partial. Он не является исполнением полной новой библиотеки. Сетевые адаптеры, запись в Drive, публикация, расписание и multi-worker execution не имитируются.

## Приоритет действующего порядка

instructions/operating-policy.md: пять файлов карточки и реальная приёмка Нины, отдельные факты утверждения/команды Игоря, разрешённый этап и явные ограничения обязательны для любого каталога. Technical completed не равен приёмке. Нет доверенного reader решений/общей очереди; клиентские переходы без проверенных внешних решений закрыты.
