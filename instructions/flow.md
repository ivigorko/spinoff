# Полный цикл: действующий порядок пользователя

Основа порядка и приёмки — instructions/operating-policy.md. Upstream даёт подробные процедуры, но не разрешение пропустить этап. Пять отдельных файлов карточки → настоящая приёмка Ниной → команда Игоря → рынок/алгоритмы → конкуренты → семантика → приёмка Ниной → команда → аудит (обход первым, независимые направления параллельно) → приёмка Ниной → стратегия/матрица/90 дней → утверждение Игоря и отдельный запуск → исполнение → приёмка/публикация по действующему маршруту/вторая проверка → измерение и отчёт → пересмотр.

`agency-cycle` связывает предметные продукты; external reviews не симулируются автоматическими узлами. Для частной задачи `role:`/`team:` или один из 11 workflows сохраняет минимальный scope, но получает реальные принятые предпосылки и не обходит общий gate. Исследование/аудит/стратегия при явном запрете конкретного проекта не начинаются из-за работы над репозиторием.

`seo gates` показывает operating readiness. `start` замораживает contract4, `source` сохраняет raw/provenance, `template` — незаполненный каркас, `submit` — техническая проверка продукта и точных parents. `nina_acceptance` отображается отдельно. Without authenticated decision reader client phases fail closed; такого bridge в поставке пока нет. Машинный completed и средний quality score не создают настоящее решение Нины.

При partial dependencies итог остаётся partial; приёмка фазы не принимает частичный продукт за полный. Сохраняются предметные QA/currentness, source chronology/scope/hash, release/verify/measurement contracts и различение prepared/applied/verified/measured. Независимые готовые задачи разрешённого этапа могут выполняться одновременно; блокер доступа останавливает соответствующие зависимости. Общая очередь и многопользовательский диспетчер не реализованы.

Полный цикл вправе ждать реальный разрешённый релиз, вторую проверку и закрытое окно аналитики. Не генерировать фиктивные approvals/releases/эффект. В разработке используются явно синтетические example fixtures; это не клиентская приёмка.
